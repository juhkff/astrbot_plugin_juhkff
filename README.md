# 综合插件

AstrBot 多功能插件：主动群聊、分享卡片解析、偷表情、日报、Pixiv 订阅与取图、帮助图。各功能可独立开关。

## 安装

1. 在 AstrBot 插件管理中，通过[本仓库地址](https://github.com/juhkff/astrbot_plugin_juhkff)安装。
2. 在 **AstrBot 使用的 Python 环境**中，从 AstrBot 根目录执行：

   ```bash
   python -m pip install -r data/plugins/astrbot_plugin_juhkff/requirements.txt
   python -m playwright install chromium
   ```

3. 重载插件，在「插件管理 → 综合插件 → 设置」中启用所需功能、选择接收群。修改定时任务后需重载插件。

日报和帮助图需要 Chromium 及中文字体；主动群聊需要 Redis。仅使用其他功能时无需配置 Redis。

## 常用指令

以下为默认指令，前缀以 AstrBot 配置为准。日报和 Pixiv 指令在群聊中使用。

| 指令 | 用途 |
| --- | --- |
| `/juhkff` | 查看插件状态 |
| `#帮助` | 查看已启用功能的帮助 |
| `#日报` | 获取今日日报 |
| `#pixiv订阅 UID` | 当前群订阅画师，例如 `#pixiv订阅 123456` |
| `#pixiv取消订阅 UID` | 当前群取消画师订阅 |
| `#pixiv日榜` / `#pixiv周榜` / `#pixiv月榜` | 获取榜单，数量在设置页调整 |
| `#pixiv随机 [关键词]` | 随机取图，可按关键词或标签搜索 |
| `#pixiv作品 ID或URL [第N张]` | 获取作品，默认全部分页；追加 `第2张` 可只看第二页 |

Pixiv 默认允许省略 `pixiv`，如 `#订阅 123456`、`日榜`、`随机 风景`。卡片解析和偷表情自动处理群消息，无需指令。

## 功能设置

完整选项见 WebUI 设置页。主动群聊及 Pixiv 的各项自动推送默认关闭；网络代理和时区在「全局设置」中配置，日志由各功能的「打印日志」开关控制。

### 主动群聊

启用前准备可连接的 Redis，在设置页填写地址（默认 `redis://localhost:6379/0`），选择生效群、聊天模型和人格。模型账户、人格及知识库需先在 AstrBot 中创建。

普通群消息默认以 20% 概率接话，可按群调整；@ 和唤醒词按 AstrBot 的唤醒规则处理。图片可直接交给视觉模型，或先转述成文字。群聊历史保存在 Redis，若需在 Redis 重启后保留历史，请为 Redis 开启持久化。

建议禁用官方 `astrbot` 系统插件，避免重复接话；需要 `/reset`、`/new` 等命令时，保留 `builtin_commands` 插件。

### 卡片解析、偷表情与日报

- **卡片解析**：自动解析 B 站、小黑盒等分享卡片，不处理普通文字链接。
- **偷表情**：默认收藏同群 72 小时内第二次出现的图片，每群最多 30 张；可配置本地表情包作为备用。
- **日报**：提供五款样式，可手动获取或定时推送。自动推送需选择接收群；可开启提前生成以减少等待。

### Pixiv

先确认 AstrBot 能访问 Pixiv；需要代理时，在全局设置填写可用的 HTTP 代理。可选填写 Pixiv Cookie 中 **PHPSESSID 的值**，访问 R18 内容和不定期发图需要有效登录态。

| 功能分组 | 设置方式 |
| --- | --- |
| 画师订阅 | 群内发送订阅指令，或编辑「订阅列表」；默认每 60 分钟检查新插画，不包含漫画、小说 |
| 榜单设置 | 调整取图数量；可单独开启定时日榜和榜单变动监测，并选择接收群 |
| 随机作品设置 | 调整手动随机取图数量、日榜候选池页数和搜索页数 |
| 不定期发图 | 选择接收群、等待间隔和最低浏览量，按随机间隔推送推荐作品 |

首次订阅及进程重启后不补推旧作或停机积压；订阅配置会保留。多页作品默认发送全部分页，注意取图数量和等待时间。

**内容与图片发送**：R18 默认过滤，可改为仅发链接或发送原图，并通过「分群内容规则」单独设置。图片传递默认使用本地文件，要求 AstrBot 与协议端能读取相同路径；独立部署或未共享目录时请选择 Base64。图片缓存默认保留 7 天。

**翻译**：标题与简介翻译、图片文字翻译分别开启。图片文字翻译可选：

- **纯文本**：选择支持图片输入的识图模型，在原图后附译文。
- **内置嵌字**：选择支持图片的翻译模型（留空用当前聊天模型），由模型识别、翻译并定位文字，再在本地排版：横排译文放原文下方或上方，竖排放左侧或右侧，避让已识别的原文和其他译文框；根据译文位置的局部背景自动选色，使用加粗实心字和细描边，不加背景或边框，字号随图片尺寸调整。保留原文，不擦字、不扫描画面空白。无需百度凭据；需安装中文字体，见下方常见问题。
- **百度嵌字**：在[百度翻译开放平台](https://api.fanyi.baidu.com/product/22)开通图片翻译，填写应用 AppID 和密钥，由云端翻译并回填图片，无需本地模型。使用的是翻译开放平台凭据，非百度智能云 APIKey / SecretKey；费用和免费额度以百度账户为准。

百度要求 PNG/JPEG、不超过 4 MiB，最短边至少 30px、最长边不超过 4096px，长宽比不超过 3:1，详见[接入文档](https://api.fanyi.baidu.com/doc/26)。超出限制或翻译失败时保留原图；R18 仅发链接时使用纯文本译文。小内存服务器建议降低「共享处理池并发上限」。

使用支持工具调用的聊天模型时，也可唤醒 AI 后说“看看今天的 Pixiv 榜单”“找一张风景插画”。请在 AstrBot 工具管理中启用本插件的三个 Pixiv 工具；多页翻译耗时较长时，可适当增加框架的工具调用超时。

## 常见问题

**日报或帮助图的中文显示为方框**

在 AstrBot 实际运行的系统或容器中，按系统选择以下命令安装中文字体，然后重启 AstrBot：

```bash
# Ubuntu / Debian
sudo apt-get update
sudo apt-get install -y fontconfig fonts-noto-cjk

# Rocky / AlmaLinux / RHEL（dnf）
sudo dnf install -y fontconfig google-noto-sans-cjk-ttc-fonts google-noto-serif-cjk-ttc-fonts
```

日报若仍使用旧图，清理当天已缓存的日报图片后重新获取。

**设置代理后仍无法访问 Pixiv**

确认代理能被 AstrBot 所在环境访问，且提供 HTTP 代理。Docker 中的 `127.0.0.1` 指向容器自身；Fake-IP 模式可能被网络安全校验拒绝。

**配置和数据在哪里**

配置位于 `data/config/astrbot_plugin_juhkff_config.json`；表情、日报和 Pixiv 缓存位于 `data/plugin_data/astrbot_plugin_juhkff/`。迁移时建议一并备份。
